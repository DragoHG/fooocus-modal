# Contribution notes

Public contribution guidance lives in [CONTRIBUTING.md](../../CONTRIBUTING.md).

Practical checklist for this repo:

1. No secrets, `.env`, or private `models.txt` in commits
2. Prefer plain ASCII punctuation in docs and UI (`-`, `...`)
3. Update `docs/audit/CHANGELOG.md` for meaningful changes
4. Keep product-facing docs written for end users (clear outcomes, no internal process jargon)
