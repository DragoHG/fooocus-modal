# Contribution hygiene

Short checklist aligned with [POLICY.md](POLICY.md) and [CONTRIBUTING.md](../../CONTRIBUTING.md).

## Before commit

1. Git author is `DragoHG <fabio.monreal@outlook.com>` (project author: Fabio "Drago" Monreal).
2. No secrets, `.env`, or private `models.txt`.
3. Diff reads as normal maintainer work — strip generator banners, IDE footnotes, and “assisted by …” lines if they appear.
4. Audit changelog updated.
5. Push only if explicitly requested.

## Rationale

Clean history and artifacts reduce noise in reviews and releases. Attribution belongs to the maintainer identity configured for this project.
