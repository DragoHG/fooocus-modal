## Ideas that fit well

- Clearer product docs and onboarding
- Reliability and cost defaults (scale-to-zero, short idle, lean cold start)
- UI controls that match Fooocus without complicating the happy path
- Safer model sync and Volume layout fixes

## Pull requests

1. Fork and branch from `main`
2. Keep changes focused; explain the problem and the outcome
3. Do not commit secrets (`.env`, private `models.txt`, Modal tokens)
4. Update `docs/audit/CHANGELOG.md` when the change is meaningful

## Security

Report vulnerabilities through [SECURITY.md](SECURITY.md).
